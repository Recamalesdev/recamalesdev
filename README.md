### Hola, soy Bernardo Recamales 👋

Indie Hacker y Arquitecto de Sistemas desde Bornos, Andalucía 🏔️. No sigo el camino tradicional: diseño sistemas y desarrollo software propio aplicando la disciplina del **Trail Running** y la filosofía de **Deep Work** al código (enfoque total, mejora constante y resultados sólidos).

- 🔭 **Proyecto actual:** Construyendo **ZÉNIT** — PWA SaaS premium de Trail Running basada en el Método Canales, con arquitectura SDD + OpenSpec.
- 🚀 **Enfoque profesional:** Calidad sobre cantidad, arquitectura limpia (React 19, TypeScript strict, Supabase) y soluciones reales orientadas a rendimiento y conversión.
- 💡 **Filosofía:** Cada línea de código tiene una razón documentada antes de existir.
